# 印刷套准复核台

接口只把印张偏差放进待处理队列。另一个进程用行锁领走一条，算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

顶栏另有**重投台**页：待处理行可由印刷员改青、品两个偏差后重新排队（状态仍是待处理、排到队尾），服务端留下改前改后的重投履历；领取中与已出结论的行不可改，只读账号只能看履历。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3194 |
| 接口 | http://localhost:8194 |
| PostgreSQL | localhost:54394 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| printer | print123456 | 可送复核、可改待处理行偏差重投 |
| checker | check123456 | 只看（含重投履历），不能改偏差 |

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| PATCH | /api/jobs/{id}/deviations | 改待处理行青品偏差并重排队，写一条重投履历；非待处理返回 409，只读账号返回 403 |
| GET | /api/requeue-logs?job_id= | 重投履历（改前/改后），登录即可看 |

## 启动

```bash
cd projects/15-print-register-review
docker compose up --build
```

## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准。
2. 再送一条青偏差 0.05 的印张，状态先是待处理；在重投台选中该行把青偏差改大（如 0.5）后确认重投，状态仍是待处理，重投履历可见改前 0.05、改后 0.5；随后结论为套不准。
3. 领取中、已出结论的行改不了偏差；checker 能打开重投台看履历，但没有改偏差输入与确认按钮。
