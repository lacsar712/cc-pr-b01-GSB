# 印刷套准复核台

接口只把印张偏差放进待处理队列。另一个进程用行锁领走一条，算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

待处理记录允许印刷员改青、品两色偏差后重新排队：状态保持待处理，服务端留下重投履历（改前/改后）。领取中（running）与已出结论（done）的记录不可改。顶栏可切到独立的重投台页，页内含待处理列表、改偏差区与重投履历三块；只读账号能看履历、不能改偏差。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3194 |
| 接口 | http://localhost:8194 |
| PostgreSQL | localhost:54394 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| printer | print123456 | 可送复核、可改待处理偏差并重新排队 |
| checker | check123456 | 只看（含重投履历，不能改偏差） |

## 启动

```bash
cd projects/15-print-register-review
docker compose up --build
```

## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准。
2. 再送一条青偏差 0.5 的印张，状态先是待处理，随后变成套不准。
3. checker 没有送复核按钮。
4. 顶栏进入重投台：printer 选一条待处理记录，在改偏差区把青、品偏差改大后点“确认重投”，状态仍为待处理；worker 领走后按新偏差出结论，重投履历里能看到每一次的改前/改后值。
5. 领取中与已出结论的记录改偏差返回 409；checker 调改偏差接口返回 403，但能正常查看重投履历。
